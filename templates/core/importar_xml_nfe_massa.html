Importação em Lote de XMLs
Instruções:
  • Selecione múltiplos arquivos XML (.xml) de notas fiscais para importação em massa.
  • O sistema tentará associar cada nota fiscal ao pedido correspondente através do número informado no campo "Informações Complementares" (infCpl).
  • As notas que forem associadas com sucesso serão incluídas automaticamente nos pedidos.
  • As notas que não forem associadas serão listadas para resolução manual.
  • O sistema também tentará extrair a data prevista de entrega pelo fornecedor do campo "Informações Complementares".

É possível selecionar múltiplos arquivos de uma só vez.
O sistema automaticamente extrai o número do pedido e também buscará datas no formato DD/MM/YYYY ou YYYY-MM-DD no campo "Informações Complementares" (infCpl) próximas a termos como "PREVISÃO ENTREGA", "PREV.ENTREGA", "DATA ENTREGA", etc. para atualizar a previsão de entrega do pedido.

Dicas para melhor associação de XMLs aos pedidos

Para garantir que o sistema associe corretamente as notas fiscais aos pedidos, informe os fornecedores que incluam as seguintes informações no campo "Informações Complementares" (infCpl) das notas fiscais:

Informação Formato recomendado Exemplo
Número do Pedido #PEDINT_123# (formato preferido) ou qualquer padrão abaixo: #PEDINT_123#, PEDIDO: 123, PEDIDO EXTERNO 123, O.C.: 123
Previsão de Entrega "ENTREGA PREVISTA" ou "PREVISÃO ENTREGA" seguido da data "PREVISÃO ENTREGA: 15/06/2025" ou "ENTREGA PREVISTA 2025-06-15"
Importante: O sistema reconhece diversos formatos de referência a pedidos, mas o formato #PEDINT_NumeroDoPedido# é o mais confiável para garantir a associação correta.
