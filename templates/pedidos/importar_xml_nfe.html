Instruções

Carregue o arquivo XML da nota fiscal para importar automaticamente os dados.

  • O sistema tentará identificar automaticamente o número do pedido no XML.
  • A busca é feita no campo "Informações Complementares" (infCpl) da nota.
  • O número do pedido deve estar em um formato reconhecível, como "Pedido #123", "Ordem: 123".
  • Se o pedido não for encontrado automaticamente, você será redirecionado para selecioná-lo manualmente.
  • Apenas pedidos com status "Aprovado" serão alterados automaticamente para "Pedido Enviado" ao importar a nota fiscal.
  • Se o pedido já tiver sido entregue, você deverá atualizar o status manualmente para "Entregue".
  • O sistema também extrairá automaticamente a previsão de entrega do fornecedor, se disponível no campo "Informações Complementares".
