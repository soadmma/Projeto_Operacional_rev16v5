Regras para Importação
  • Os campos Nome do Orçamento, Produto, Quantidade e Valor Unitário são obrigatórios.
  • O produto deve já estar cadastrado no sistema.
  • O fornecedor é opcional, mas se informado, o CNPJ deve existir no sistema.
  • O valor unitário deve ser informado usando ponto (.) como separador decimal.
  • A coluna Quantidade deve conter apenas números inteiros.
  • A coluna Valor Unitário deve conter o preço unitário do produto.
  • A coluna Fornecedor (CNPJ) deve conter o CNPJ do fornecedor se desejar vinculá-lo.
  • A coluna Forma de Pagamento (opcional) deve conter uma das opções: À Vista, 30 Dias, 60 Dias, 90 Dias, Parcelado ou Outros.
  • A coluna Data Prevista de Entrega (opcional) deve estar no formato dd/mm/aaaa.
